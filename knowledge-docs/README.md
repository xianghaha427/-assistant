## 二、导入 Dify 知识库操作步骤

### 第 1 步：创建知识库

1. 登录 Dify 控制台，进入"知识库"页面，点击"创建知识库"；
2. 选择"导入已有文本"，上传本目录下全部 8 个 `.md` 文件；
3. 知识库命名为"华信证券企业知识库"。

### 第 2 步：设置分段与索引

1. 分段设置选择**"自动分段与清洗"**（建议 500 token，重叠 50）；或使用"自定义"按 Markdown 标题分段（以 `#` 分隔），效果更好；
2. 索引方式务必选择**"高质量"**（High Quality，使用 Embedding 向量索引），保证语义检索精度；
3. 点击"保存并处理"，等待 8 个文档分段、向量化完成。

### 第 3 步：绑定到知识问答助手应用

1. 进入"知识问答助手"应用（或新建一个 Chatflow 应用）；
2. 在编排画布中找到**"知识检索"节点**，点击配置；
3. 添加上一步创建的"华信证券企业知识库"；
4. 检索设置建议：TopK = 3，Score 阈值 0.5，可开启 Rerank 模型提升排序质量；
5. 将知识检索节点的输出连接到 LLM 节点的上下文变量，发布应用。

### 第 4 步：验证

在应用预览窗口输入下方"演示问答案例"逐条验证，确认回答内容与知识库原文一致且引用来源正确。
